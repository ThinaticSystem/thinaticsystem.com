# アプリサービス

## 役割

このディレクトリは、画面をまたいで使うloading、notification、navigationの状態と操作をまとめる。コンポーネントはサービスの状態を表示し、サービスは画面固有のDOM構造を持たない。

## 構成

各サービスの実装と規範specを同じ階層に置く。具体的な過去不具合を再発させない確認は `.regression.spec.ts` に分け、通常の仕様例と目的を混ぜない。

## 必要な詳細

loadingは開始・完了・失敗の順序を、notificationは表示・交換・消去・購読解除の寿命を明示的に確認する。通知を送る側が購読を所有しないよう、破棄時の挙動もテストする。
