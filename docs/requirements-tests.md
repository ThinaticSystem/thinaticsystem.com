The ordinary suite's creation tests are retained where they document Angular wiring, but they are not used as evidence for the boundary rows above. The rows marked DEBT FAIL are preserved baseline findings, not green requirements; fixing them requires separate scope approval and focused assertions. The known-defect suite contains ordinary failing assertions (no skip/todo/fails inversion) and is evaluated by `test/known-defects.json`. The supported Vitest 4 reporter emits assertion identity, error name, origin, and source location as structured evidence; the adapter accepts multiple describe suites using the pinned hierarchy semantics (`file` plus each ancestor suite), requires suite and test counters to reconcile with the report, rejects unknown assertion identities, non-test assertion origins, arbitrary error kinds, runner/setup errors, and unexpected passes, and requires the child process to exit with status 1. Real runner probes cover assertion, test-body TypeError, beforeEach TypeError, afterEach TypeError, and unhandled asynchronous TypeError outcomes.
